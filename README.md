# AERO PC MONITOR

Компактный настольный виджет для Windows 10/11 в стиле Aero Glass.

## Показатели
- Процессор: название, физические ядра и потоки, загрузка и температура.
- Видеокарта: название активного адаптера, загрузка 3D и температура.
- ОЗУ: занято / всего и полоса заполнения.
- Накопители: буква раздела, свободное и общее место, процент заполнения и цветная полоса.
- Сеть: имя Wi-Fi, локальный IPv4, скорость приёма и отправки.

## Датчики
Загрузка видеокарты считывается через системный счётчик Windows GPU Engine. Название адаптера берётся из реестра Windows. Температуры считываются из WMI LibreHardwareMonitor/OpenHardwareMonitor; для CPU дополнительно используется доступный ACPI thermal-zone датчик. Если материнская плата/драйвер не публикует датчик или не запущен совместимый провайдер, отображается «н/д». Значения не подменяются фиктивными.

Для полного набора температур установите и запустите LibreHardwareMonitor. В нём откройте Options → Remote Web Server → Run (локальный порт 8085). Виджет читает актуальный REST-интерфейс `/data.json`; для старых версий также оставлен WMI-запасной вариант. Некоторые датчики Xeon или RX 580 могут быть недоступны из-за ограничений BIOS/драйвера.

## Производительность и окно
Долгие запросы к Windows выполняются в фоновом потоке, интерфейс не ждёт опроса GPU/температур/сети. Виджет открывается в правом верхнем углу. Кнопка «–» сворачивает окно в панель задач.

## Настройки
Шестерёнка открывает настройки оформления: прозрачность и оттенок меняются при перемещении ползунков; «Применить» сохраняет параметры, «Отмена» откатывает их. Настройки хранятся в профиле Windows.

## Сборка
GitHub Actions собирает Windows EXE через PyInstaller. Размер зависит от Python и библиотек; точный размер печатается в журнале сборки. Цель 5–10 МБ не гарантируется.

## Антивирус
PyInstaller one-file иногда вызывает ложные срабатывания из-за самораспаковки. Не отключайте антивирус и не добавляйте файл в исключения без проверки. При сомнениях проверьте файл Microsoft Defender и VirusTotal; подтверждённое ложное срабатывание можно отправить Microsoft на анализ.
