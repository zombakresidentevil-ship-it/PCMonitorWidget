# AERO PC MONITOR

Компактный настольный виджет для Windows 10/11 в стиле Aero Glass.

## Что показывает
- Процессор: название, физические ядра и логические потоки, загрузка и температура.
- Видеокарта: загрузка GPU и температура.
- Оперативная память: занято / всего и полоса заполнения.
- Все обнаруженные дисковые разделы: буква, свободное место и общий объём в ГБ, процент заполнения и цветная полоса.
- Сеть: имя Wi-Fi, локальный IPv4, скорость приёма и отправки.

## Температуры
Для температурных показаний используется WMI-провайдер LibreHardwareMonitor или OpenHardwareMonitor. Если совместимый провайдер не установлен или его WMI-доступ не включён, виджет показывает «н/д», а не выдуманное значение. Загрузка GPU берётся из системного счётчика Windows GPU Engine, если он доступен.

## Настройки
Шестерёнка открывает режим оформления:
- прозрачность меняется сразу при движении ползунка;
- оттенок интерфейса плавно меняется при движении второго ползунка;
- «Применить» сохраняет параметры;
- «Отмена» откатывает изменения к значениям до открытия настроек.
Настройки сохраняются в профиле пользователя Windows.

## Сборка
GitHub Actions собирает Windows EXE через PyInstaller. Размер зависит от версии Python и библиотек; точный размер печатается в журнале сборки. Цель 5–10 МБ не гарантируется.

## Антивирус
PyInstaller one-file иногда вызывает ложные срабатывания из-за самораспаковки. Не отключайте антивирус и не добавляйте файл в исключения без проверки. При сомнениях проверьте файл Microsoft Defender и VirusTotal; подтверждённое ложное срабатывание можно отправить Microsoft на анализ.
