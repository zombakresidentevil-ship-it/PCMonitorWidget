# Aero Monitor — Python edition

Лёгкий виджет для Windows 10/11 в компактном стиле Aero Glass.

## Показатели
- CPU: загрузка.
- GPU: загрузка через системный счётчик Windows GPU Engine (если он доступен).
- RAM: занято / всего.
- Диски: заполненность C: и D:.
- Сеть: Wi-Fi SSID, локальный IPv4, скорость приёма и отправки.

Температуры CPU/GPU пока показываются как «—»: Windows не предоставляет универсальный безопасный интерфейс для чтения этих датчиков. Для температур нужен отдельный сенсорный провайдер; неизвестные драйверы ради виджета не устанавливаются.

## Сборка
GitHub Actions собирает один EXE с PyInstaller. Размер зависит от версии Python и библиотек; workflow печатает точный размер в журнал сборки. Цель — 5–10 МБ, но это не гарантируется: Tkinter и интерпретатор Python имеют собственный вес.

## Антивирус
PyInstaller one-file иногда вызывает ложные срабатывания из-за самораспаковки. Код не обфусцируется и не скрывается. Если Защитник Windows пометит файл, не отключайте антивирус: проверьте файл Microsoft Defender и VirusTotal, а при подтверждённом ложном срабатывании отправьте образец Microsoft на проверку.
